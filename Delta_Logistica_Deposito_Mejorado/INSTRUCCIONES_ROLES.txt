LOGISTICA DELTA - ROLES Y BASE COMPARTIDA

Base de datos
- Instalación nueva: importar logistica_delta.sql en una base vacía llamada logistica_delta.
- El archivo logistica_delta.sql debe ser idéntico al archivo database/logistica_delta.sql del proyecto web.
- Para conservar la base del hosting, hacer respaldo y ejecutar una sola vez database/migrar_host_s11.sql desde el proyecto web. No importar el SQL de instalación sobre una base existente.

Configuración de conexión Java
- DELTA_DB_URL: URL JDBC con el servidor y la base compartida.
- DELTA_DB_USER: usuario de MySQL.
- DELTA_DB_PASSWORD: contraseña de MySQL.
- Estas variables también se pueden proporcionar como propiedades Java del mismo nombre.
- La aplicación PHP y la aplicación Java deben apuntar al mismo servidor y base.

Roles
- ADMINISTRADOR: consulta general, gestiona usuarios, operaciones, historial y resumen.
- ADMINISTRACION: consulta general y resumen operativo.
- OPERADOR_DEPOSITO: consulta, asigna paquetes preparados, cambia estados y registra movimientos de depósito.
- CHOFER: consulta sus envíos asignados, actualiza entregas y registra incidencias.
- CLIENTE: consulta sus propios envíos y su historial.
- ATENCION_CLIENTE: se utiliza exclusivamente desde el panel web de atención al cliente.
- SUPERADMIN: gestiona los roles elevados desde Java; la cuenta inicial debe promoverse de forma controlada por la administración de la base.

La cuenta de práctica inicial es admin / DeltaAdmin123. Cambiarla antes de publicar una instalación nueva.
